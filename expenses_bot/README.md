# 💸 Розхідники — бот обліку витрат (@rozhodnikibot)

Telegram-бот, який записує витрати одним повідомленням і показує,
куди пішли гроші за день, тиждень і місяць.

```
Ти:  250 їжа обід з друзями
Бот: ✅ Записав: −250 грн · 🍽 їжа
     обід з друзями

     За місяць: 4 830 грн
     🟢 Лишилось 10 170 грн до ліміту
     /del 42 — видалити
```

## Як записувати

| Пишеш | Що вийде |
|---|---|
| `250 їжа обід з друзями` | 250 грн, категорія «їжа», коментар |
| `їжа 250` | порядок не важливий |
| `120 кава` | категорія вгадається сама → «їжа» |
| `1.5к продукти` / `2k продукти` | «к» = тисяча → 1500 / 2000 |
| `250,50 аптека` | кома або крапка в копійках |
| `100 прод` | скорочення категорії → «продукти» |
| `+5000 зарплата` | плюс = дохід, а не витрата |

Категорію можна не писати: бот упізнає слова на кшталт *кава, сільпо, таксі,
бензин, аптека, кіно, netflix, київстар, оренда* — з поправкою на відмінки
(`кави`, `аптеці`, `бензину`). Не впізнав — покладе в «інше», а слово лишить
у коментарі.

## Кнопки

- Під кожним записом — кнопки всіх категорій: тицяєш, і запис миттєво
  переїжджає в іншу категорію (не треба переписувати), плюс 🗑 «Видалити».
- Під звітом — «Сьогодні / Тиждень / Місяць» і «🗂 Категорії»: звіт
  перемальовується прямо в тому ж повідомленні.
- У списку категорій кожна категорія — кнопка: показує останні записи по ній
  за місяць з номерами (`#42`), щоб зручно видаляти.

## Команди

| Команда | Опис |
|---|---|
| `/day`, `/yesterday` | звіт за сьогодні / вчора |
| `/week`, `/month` | за поточний тиждень / місяць |
| `/cats` | категорії і скільки на кожну пішло за місяць |
| `/addcat кафе 🍰` | додати свою категорію (емодзі не обов'язкове) |
| `/delcat кафе` | прибрати категорію (старі записи лишаються) |
| `/limit 15000` | місячний бюджет; `0` — вимкнути |
| `/undo` | скасувати останній запис |
| `/del 42` | видалити запис за номером |
| `/export` | вивантажити всі записи у CSV |
| `/help` | шпаргалка |

Ліміт показується в кожному звіті й після кожного запису:
🟢 до 80%, 🟡 80–100%, 🔴 перевищено.

Категорії за замовчуванням: 🍽 їжа, 🛒 продукти, 🚌 транспорт, 🏠 житло,
📱 звязок, 💊 здоровя, 🎬 розваги, 👕 одяг, 🎁 подарунки, 📦 інше.

## Запуск

```bash
cd expenses_bot
pip install -r requirements.txt
cp .env.example .env       # встав EXPENSES_BOT_TOKEN від @BotFather
python bot.py
```

Docker:

```bash
cd expenses_bot
cp .env.example .env
docker compose up -d --build
docker compose logs -f
```

VPS + systemd:

```bash
sudo useradd -r -m -d /opt/rozhodniki-bot botuser
sudo -u botuser git clone <repo> /opt/rozhodniki-bot
cd /opt/rozhodniki-bot/expenses_bot
sudo -u botuser python3 -m venv .venv && sudo -u botuser .venv/bin/pip install -r requirements.txt
sudo -u botuser cp .env.example .env && sudo -u botuser nano .env
sudo cp rozhodniki-bot.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now rozhodniki-bot
```

## Налаштування (`.env`)

| Змінна | За замовч. | Опис |
|---|---|---|
| `EXPENSES_BOT_TOKEN` | — | токен бота (обов'язково) |
| `DB_PATH` | `data/expenses.db` | файл бази SQLite |
| `CURRENCY` | `грн` | валюта у звітах |
| `TZ` | `Europe/Kyiv` | пояс, у якому рахуються день/тиждень/місяць |

```
day - витрати за сьогодні
```

## Перевірка

```bash
python selftest.py     # 228 перевірок, Telegram і токен не потрібні
```

Покриває: кожну категорію явно і за ключовим словом, відмінки, формати сум,
усі команди, всі inline-кнопки (періоди, категорії, зміна категорії, видалення),
ліміт, `/undo` і `/del`, CSV-експорт, ізоляцію даних між чатами.

## Структура

```
bot.py        точка входу: aiogram, команди, текст, кнопки
keyboards.py  inline-клавіатури: категорії, періоди, видалення
parser.py     розбір «250 їжа обід» на суму / категорію / коментар
db.py         SQLite: користувачі, категорії, записи
reports.py    підсумки за період, бари, ліміт, формат грошей
config.py     конфіг з .env
selftest.py   офлайн-перевірка всієї логіки
```
