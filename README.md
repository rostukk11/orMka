# 🤖 Spread Scanner Bot

Telegram-бот, що моніторить **спреди одного токена між біржами** (CEX + DEX) і
надсилає сигнал, коли різниця ціни перевищує заданий поріг.

Для кожного знайденого спреду бот показує:

- **відсоток спреду**;
- **де купити** (біржа з найнижчим `ask`) і **де продати** (біржа з найвищим `bid`);
- чи можливий **вивід** монети з біржі купівлі (✅/⛔/❔) і **ввід** на біржу продажу —
  це ключове для реального арбітражу.

> ⚠️ Інструмент інформаційний. Спред ≠ гарантований прибуток: є комісії, сліпедж,
> час переказу, ліміти й мережеві збори. Перевіряйте все вручну перед угодою.

## Як працює

- **CEX** — через [`ccxt`](https://github.com/ccxt/ccxt): ціни (`bid`/`ask`) і статус
  вводу/виводу монет (`fetch_currencies`). Підтримується багато бірж: Binance, Bybit,
  OKX, KuCoin, Gate, MEXC, HTX, Bitget, Kraken, Coinbase тощо (можна вказати `all`).
- **DEX** — через публічний API [DexScreener](https://docs.dexscreener.com/) (без ключів).
  У DEX немає поняття «ввід/вивід», тож для нього показується лише ціна.

Логіка спреду: серед усіх бірж, де є ціна токена, береться **найдешевша купівля**
(min ask) і **найдорожчий продаж** (max bid); спред = `(sell - buy) / buy * 100%`.

## Встановлення

```bash
pip install -r requirements.txt
cp .env.example .env
# відкрий .env і встав TELEGRAM_BOT_TOKEN від @BotFather
python bot.py
```

## Команди бота

| Команда | Опис |
|---|---|
| `/start` | підписатися на авто-алерти |
| `/stop` | відписатися |
| `/top` | топ спредів зараз |
| `/spread BTC` | спред конкретного токена |
| `/threshold 2` | змінити поріг алерта (%) |
| `/status` | поточні налаштування і список бірж |
| `/help` | довідка |

## Налаштування (`.env`)

| Змінна | За замовч. | Опис |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — | токен бота (обов'язково) |
| `TELEGRAM_CHAT_ID` | — | (опц.) чат для алертів за замовчуванням |
| `QUOTE` | `USDT` | котирувальна валюта |
| `MIN_SPREAD_PERCENT` | `1.0` | поріг алерта, % |
| `MAX_SPREAD_PERCENT` | `50` | відсікання аномалій (0 = без ліміту) |
| `SCAN_INTERVAL` | `60` | інтервал сканування, с |
| `ALERT_COOLDOWN` | `900` | пауза по токену після алерта, с |
| `CEX_EXCHANGES` | список | біржі ccxt через кому (або `all`) |
| `ENABLE_DEX` | `true` | вмикає DexScreener |
| `TOKENS` | список | токени; порожньо = авто-перетин ринків CEX |

## Структура

```
bot.py            # точка входу: aiogram, команди, цикл алертів
scanner.py        # збір цін з усіх бірж і розрахунок спредів
exchanges/cex.py  # CEX через ccxt (ціни + ввід/вивід)
exchanges/dex.py  # DEX через DexScreener
formatting.py     # форматування повідомлень
storage.py        # підписники й налаштування (JSON)
config.py         # конфіг з .env
```
