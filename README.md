# 🤖 Spread Scanner Bot (DEX ↔ CEX)

Telegram-бот, що моніторить **різницю ціни токена між DEX і CEX** і надсилає
сигнал **LONG/SHORT**, коли різниця перевищує заданий поріг.

Приклад сигналу:

```
📈 Сигнал LONG для LAB

🔹 DEX: 12.79838744 USDT
🔹 Gate: 9.92434000 USDT

🟢 Разница: 22.46%

Gate Futures:
🔹 Объём (24ч): 383 138 092 USDT
🔹 Депозит: ✅
🔹 Вывод: ✅

DEX:
🔹 Объём: 17 191 618 USDT
🔹 Ликвидность: 3 279 671 USDT
🔹 Сеть: bsc
🔹 Контракт: 0x7ec43cf65f1663f820427c62a5780b8f2e25593a

LAB
🔹 Сигналов за день: 394
✅ Успешных сигналов: 15 ❌ Неудачных: 12
```

## Як працює

- **CEX** — через [`ccxt`](https://github.com/ccxt/ccxt): ціна та обсяг 24г
  (за замовчуванням ринок `swap` — ф'ючерси/безстрокові), а також статус
  вводу/виводу монети (`fetch_currencies`, спот-гаманець).
- **DEX** — через публічний API [DexScreener](https://docs.dexscreener.com/):
  ціна, обсяг, ліквідність, мережа та адреса контракту найліквіднішої пари.

Логіка: для кожного токена береться DEX-ціна і CEX-ціна з найбільшою різницею.
`Разница = (max − min) / max × 100%`. Якщо DEX дорожче за CEX → **LONG** на CEX
(ціна підтягнеться вгору), інакше **SHORT**.

**Статистика сигналів** рахується автоматично: кожен надісланий сигнал
збільшує лічильник за день; сигнал вважається *успішним*, якщо різниця згодом
стиснулась нижче `SUCCESS_CONVERGENCE` від стартової, і *невдалим*, якщо за
`SIGNAL_TTL` секунд цього не сталось.

> ⚠️ Інструмент інформаційний. Різниця ≠ гарантований профіт: є комісії,
> сліпедж, час і ліміти переказів, мережеві збори, фандинг по ф'ючерсах.

## Встановлення

```bash
pip install -r requirements.txt
cp .env.example .env          # встав TELEGRAM_BOT_TOKEN від @BotFather
python bot.py
```

## Команди

| Команда | Опис |
|---|---|
| `/start` | підписатися на авто-сигнали |
| `/stop` | відписатися |
| `/top` | топ сигналів зараз |
| `/signal LAB` | сигнал по конкретному токену |
| `/threshold 5` | поріг різниці (%) |
| `/status` | налаштування і список бірж |
| `/help` | довідка |

## Налаштування (`.env`)

| Змінна | За замовч. | Опис |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — | токен бота (обов'язково) |
| `TELEGRAM_CHAT_ID` | — | (опц.) чат для сигналів за замовчуванням |
| `QUOTE` | `USDT` | котирувальна валюта |
| `MIN_SPREAD_PERCENT` | `3.0` | поріг різниці, % |
| `MAX_SPREAD_PERCENT` | `80` | відсікання аномалій (0 = без ліміту) |
| `SCAN_INTERVAL` | `60` | інтервал сканування, с |
| `ALERT_COOLDOWN` | `900` | пауза по токену після сигналу, с |
| `MIN_DEX_LIQUIDITY` | `10000` | мін. ліквідність DEX-пари, USD |
| `SIGNAL_TTL` | `1800` | час життя відкритого сигналу, с |
| `SUCCESS_CONVERGENCE` | `0.5` | поріг «успіху» (частка стиснення) |
| `MARKET_TYPE` | `swap` | ринок CEX: `swap` (ф'ючерси) або `spot` |
| `CEX_EXCHANGES` | список | біржі ccxt через кому (або `all`) |
| `TOKENS` | — | токени; порожньо = авто-підбір |

## Структура

```
bot.py            точка входу: aiogram, команди, цикл сигналів
scanner.py        DEX↔CEX порівняння + оцінка успішності
exchanges/cex.py  CEX через ccxt (ціна, обсяг, ввід/вивід)
exchanges/dex.py  DEX через DexScreener (ціна, обсяг, ліквідність, контракт)
formatting.py     формат повідомлення-сигналу
storage.py        підписники, налаштування, статистика
config.py         конфіг з .env
```
